# lucky-wheel

一个六等分转盘。转盘上不写礼物名，初始状态只有颜色；转停之后才揭晓指针指到的那一格是什么。

六份礼物（从 12 点方向顺时针）：

1. Dior — Addict Lip Glow
2. YSL — Loveshine
3. Jo Malone London — 30 mL 香水
4. Jellycat
5. 信
6. 520 红包

## 跑起来

纯静态，没有任何依赖。直接双击 `index.html` 就能看；或者：

```bash
npx http-server -p 8080 .
```

## 文件

| 文件 | 干嘛的 |
| --- | --- |
| `index.html` | 页面结构，**所有文案位都在这里**，每块都有中文注释标了是第几个文案位 |
| `styles.css` | 样式。转盘尺寸、配色氛围、转动时长 `--spin-duration` 都在这 |
| `wheel.js` | 逻辑。**礼物、颜色、图片、揭晓文案都在文件最上面那一段** |
| `img/` | 四张实物图 |

## 改文案

打开 `index.html`，六个文案位分别是：

1. 小标题（eyebrow）
2. 主标题
3. 副标题
4. 正文段落 — 想多写几段就复制这一行
5. 底部小字
揭晓时礼物名下面**默认没有文案** —— 东西就是东西。只有「信」那格写了一句
（`wheel.js` 里的 `copy` 字段），因为得告诉她来找你拿。哪格不写，那一行就整行不出现。

鼠标移到任意文案位上会显示一圈虚线，方便定位。不想要这个提示的话，删掉
`styles.css` 里的 `.slot:hover` 那条规则即可。

## 换礼物 / 换颜色 / 换图

都在 `wheel.js` 顶部的 `SEGMENTS`，顺序是从 12 点方向开始顺时针：

```js
const SEGMENTS = [
  {
    brand: 'Dior',                    // 礼物名上面的小字，没有就 ''
    name:  'Addict Lip Glow',         // 转停之前不会出现在转盘上
    color: '#E0728B',                 // 转盘上这一格的颜色
    photo: 'img/dior-lip-glow.jpg',   // 揭晓时显示的实物图
  },
  ...
];
```

没有实物图的两格（信、520 红包）用这一格的颜色配个图形或一个字代替：
`svg` 填一段 SVG（信封就是这么画的），或者 `glyph` 填一个字（红包用的是「福」）。

格子数不是写死的 —— `SEGMENTS` 里放几项，转盘就分几等分。

## 实物图要不要放在转盘上

默认**不放**：转盘上只有颜色，照片只在转停揭晓时出现，所以转之前六份礼物是保密的。

想让照片直接铺进扇形（转盘更好看，但转之前就能看到六份礼物是什么），
把 `wheel.js` 里这一行改成 `true`：

```js
const SHOW_PHOTOS_ON_WHEEL = false;
```

改这一个字就够了，别的都不用动。照片会按扇形的外接矩形铺满并居中裁切，
没有照片的两格仍然是纯色。
